**Never used Git before? Start here.** This series assumes no prior knowledge. It begins with *why*
version control exists, installs Git, teaches just enough terminal, and then builds up one concept at a
time until you're comfortable with the tools experienced developers use every day: rebasing, bisecting,
worktrees, hooks and recovering "lost" work.

### How every chapter works

- **An introduction:** what you'll learn, why it matters, what you need to know first, and how long it takes.
- **Concepts explained from zero**, with diagrams, analogies and every new term defined.
- **When to use it (and when not to)**, so you can choose the right tool, not just type commands.
- **A hands-on lab** you run in your own terminal, step by step, showing the real output and explaining
  what each message means. Every lab was run and verified while writing the series.
- **Common mistakes, a recap and quiz questions** to check your understanding.

### The learning path

| Section | You'll be able to… |
| --- | --- |
| **Foundations** (1–9) | Create repositories, make clean commits, ignore files, read and search history |
| **Branching & Merging** (10–12) | Work on features in parallel, merge them, and resolve conflicts calmly |
| **Working with GitHub** (13–16) | Push to GitHub, collaborate with teammates, open and review pull requests |
| **Undo & Rewrite History** (17–22) | Undo any mistake, rebase, polish commits, move work around, recover anything |
| **Advanced Git** (23–28) | Understand Git's internals, find bugs with bisect, use worktrees, hooks and big-repo tools |
| **Real-World Playbook** (29–30) | Work faster with hacks, and fix real disasters step by step |

You'll need a computer (Windows, macOS or Linux) and about 30–60 minutes per chapter. A GitHub account
is only needed from chapter 13, and even there a local alternative is shown.

Already comfortable with the basics? Jump to [Undo Almost Anything](17-undoing-changes/index.md) or the
[Git Disasters playbook](30-git-disasters/index.md).
